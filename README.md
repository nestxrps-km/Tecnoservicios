# Tecnoservicios

Sitio web de reparación, mantenimiento e instalación de paquetería Office.

- Público en general: $500 MXN
- Estudiantes: $390 MXN
- Los botones de compra abren WhatsApp con un mensaje predeterminado.

## Uso local
Abre `index.html` en el navegador.

## Cambiar el número de WhatsApp
Edita `WHATSAPP_NUMBER` al final de `index.html` (código de país + número, sin `+`).

## Publicar con GitHub Pages
1. En GitHub: **Settings → Pages**.
2. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Guarda; el sitio quedará en `https://nestxrps-km.github.io/Tecnoservicios/`.
